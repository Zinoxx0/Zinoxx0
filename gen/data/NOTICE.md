# What's in this folder

`make_data.py` writes everything here. The daily build only reads it.

- `glyphs.json`: outlines of [Geist Mono](https://github.com/vercel/geist-font), Copyright 2023 Vercel, under the
  [SIL Open Font License 1.1](https://openfontlicense.org).
- `palettes.json`: the three desktop screenshots in `assets/`, through
  [Atom Plasma](https://github.com/Zinoxx0/Atom-Plasma)'s own palette engine.
- `libt-run.txt`: a real run of [Libft_Tester](https://github.com/Zinoxx0/Libft_Tester) on my libft.
